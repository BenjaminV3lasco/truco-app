# Contexto del proyecto

Esta carpeta conserva la memoria de producto y las decisiones de desarrollo de **Truco de Barrio**. Su objetivo es que una persona —o una herramienta de asistencia— pueda continuar el trabajo sin reconstruir el contexto desde cero.

El código sigue siendo la fuente de verdad sobre lo que está implementado. Estos documentos explican por qué existe cada decisión y qué todavía está pendiente.

## Documentos

- `product.md`: propósito, usuarios, alcance y reglas del torneo.
- `tournament-rules.md`: modalidades, formatos, puntuación y clasificación.
- `data-model.md`: entidades y relaciones independientes de la plataforma.
- `user-flows.md`: recorridos para crear, jugar, pausar y consultar torneos.
- `technical-decisions.md`: estado técnico real y decisiones de arquitectura.
- `commits.md`: Conventional Commits en inglés.
- `conventions.md`: nombres, archivos y reglas de implementación.
- `ui-style-guide.md`: dirección visual actual y decisiones aún abiertas.
- `roadmap.md`: funcionalidades implementadas y siguientes etapas.
- `security.md`: mínimos de seguridad proporcionales al proyecto.

## Cómo mantener esta carpeta

- Actualizar `product.md` cuando cambien reglas del torneo.
- Mantener el detalle de las reglas en `tournament-rules.md`.
- Registrar decisiones técnicas importantes en `technical-decisions.md`.
- Actualizar `roadmap.md` al completar o redefinir una etapa.
- Evitar documentación extensa para cambios pequeños.
- No presentar ideas futuras como funcionalidades ya implementadas.
