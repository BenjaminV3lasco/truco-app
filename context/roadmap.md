# Roadmap

El orden puede cambiar con las pruebas de uso. Los elementos completados describen el prototipo actual, no necesariamente una versión final.

## Etapa 1 — Creación básica

- [x] Pantalla inicial temática.
- [x] Carga y eliminación de participantes.
- [x] Selección de Liga, Fase de grupos o Eliminatoria directa.
- [x] Restricción de eliminatoria con cantidad impar.
- [x] Sorteo inicial de grupos.
- [x] Vista inicial de cruces y tabla de liga.
- [x] Adaptación básica a móvil.

## Etapa 2 — Torneos utilizables

- [x] Definir una primera versión del modelo de torneo y partido.
- [x] Configurar modalidad 1v1, 2v2 o 3v3.
- [ ] Gestionar equipos manuales o sorteados y validar la cantidad de jugadores.
- [ ] Configurar partidos a 15 o 30 puntos.
- [ ] Registrar resultados y ganadores.
- [ ] Calcular posiciones de Liga.
- [ ] Calcular tablas y clasificación desde grupos.
- [ ] Avanzar rondas de Eliminatoria directa.
- [ ] Incorporar el anotador de partido.
- [x] Incorporar un anotador libre desde el menú principal.
- [ ] Detectar el cierre de mano tras 20 segundos de inactividad.
- [ ] Incorporar la secuencia especial de Puntas para 3v3.
- [ ] Resolver empates relevantes con partidos adicionales a 15.
- [ ] Soportar `byes` y abandonos en llaves eliminatorias.
- [ ] Guardar y reanudar torneos en el dispositivo.
- [ ] Reemplazar el historial de muestra por datos reales.

## Etapa 3 — Experiencia y reglas

- [ ] Definir el sistema visual definitivo.
- [ ] Incorporar música o ambientación con control real de reproducción.
- [ ] Permitir nombrar el torneo.
- [ ] Configurar puntos objetivo y reglas de desempate.
- [ ] Confirmar antes de acciones que pierdan progreso.
- [ ] Agregar exportación o forma simple de compartir resultados.

## Preguntas abiertas

- ¿El máximo de 48 se aplica a jugadores físicos, como se entiende actualmente, o a participantes competitivos/equipos?
- ¿La Liga enfrenta a todos una vez o admite ida y vuelta?
- ¿Cómo se resuelve un empate total entre tres o más participantes?
- ¿Cómo afecta un abandono a partidos y tablas de Liga o Grupos?
- ¿El historial debe vivir sólo en el dispositivo o sincronizarse?
